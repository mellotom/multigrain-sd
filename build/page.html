on the module

mgs_03 · manual 1.4
alt › [ project ]opens the project page. [ 1–8 ] switch projects; x / y / z (press twice for xx / yy / zz) pick the bank of eight.
banksx 1–8 · y 9–16 · z 17–24 · xx 25–32 · yy 33–40 · zz 41–48. a lit button = that project folder exists.
[ /project ]sample loading: loads from the current project’s folder. [ /wavs ] and [ /recs ] are shared by every project.
[ ‹prev · next› ]step through the folder; long press jumps 5. press or latch the sound to audition while you browse.
file format.wav · 48 khz · 16-bit · stereo · up to 32 s. nothing else loads.
ordering/project and /wavs are indexed alphabetically; /recs newest first.
missing samplepresets remember file names. rename or move a file on a computer and the sound comes up empty until it’s back.
hold [ project ] at bootcollect + save every project: copies samples used from /wavs and /recs into each project folder.
